Permutation Importance (Accuracy Drop when Shuffled)

Each logical feature block is shuffled across held-out test records while holding other features constant. The resulting drop in test accuracy isolates how heavily the model depends on that feature. Job Role and Job Description are permuted together to prevent unaligned pairs.

Scientific Interpretability Principles
Feature Grouping

Evaluating high-level feature groups (Resume, Role, Demographics) avoids spurious TF-IDF token noise and provides robust assessment of model behavior.

Joint Permutation

Because each job description is fixed per role, Job Role and Job Description are permuted jointly to prevent unrealistic synthetic inputs.

Name Exclusion

Applicant names were completely omitted prior to feature encoding to guarantee models cannot memorize individual candidate identities.
